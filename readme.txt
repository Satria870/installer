# Aplikasi Pembelajaran Digital
 bentuk teknologi informasi yang diterapkan di bidang pendidikan berupa website yang dapat diakses di mana saja.

## Manfaat
- Mempermudah guru dalam memonitor kehadiran dan keterlibatan siswa.
- Meningkatkan keteraturan dan kedisiplinan dalam proses belajar.
- Proses pembelajaran terdokumentasi dengan baik dan dapat diakses kapan saja.
- Membantu siswa belajar secara mandiri dan terstruktur.
- Orang tua bisa memantau kehadiran dan aktivitas belajar anak secara langsung.

## Fitur-Fitur
- Absensi harian online
- Pengumpulan tugas dan Penilaian
- Materi pembelajaran
- Forum diskusi kelas
- Kalender pembelajaran
- Notifikasi otomatis

## Tech
Aplikasi ini dibuat menggunakan :
- [Netbeans] NetBeans adalah salah satu software yang sangat sering  digunakan dalam dunia programmer atau digunakan oleh banyak developer.
- [XAMPP] merupakan media atau web server localhost yang bisa digunakan secara offline.
- [Javascript] bahasa pemrograman yang digunakan dalam pengembangan website agar lebih dinamis dan interaktif.
- [Jframe] kelas di Java yang memiliki metode dan konstruktornya sendiri.
- [Google Chrome] browser web resmi dari Google, dibangun untuk menjadi cepat, aman, dan dapat disesuaikan.
- [Phpmyadmin] adalah perangkat lunak gratis yang ditulis dalam PHP , yang dirancang untuk menangani administrasi MySQL melalui web.

## Syarat

- XAMPP Control Panel 3.3.0
